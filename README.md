# 🗓️ Planif — Mon assistant de journée

Planificateur de journée multi-projets, en **un seul fichier HTML** : priorisation intelligente (impact, urgence, durée, complexité), timer discret, checklists avec modèles, dictée vocale 🎤, stats et export Google Agenda.

**Les données restent 100 % locales** (localStorage du navigateur) — rien n'est envoyé sur un serveur.

## Utilisation
- Ouvrir la page GitHub Pages du repo, puis « Ajouter à l'écran d'accueil » sur mobile (PWA, fonctionne hors-ligne).
- ☁️ Synchro multi-appareils optionnelle via un dépôt GitHub privé à soi (⚙️ → dépôt + token fine-grained « Contents » en écriture).
- ⚙️ → Exporter / Importer (JSON) pour sauvegarder ou transférer ses données entre appareils.
- 🎤 pour dicter une tâche : durée, urgence, projet et échéance sont détectés dans la phrase.
